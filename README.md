# Атлас — Telegram Mini App для онлайн-школы психологии

Премиальное мини-приложение с лид-магнитом, тапалкой и лавкой за внутреннюю валюту.

**Демо:** https://sashamatyushkin.github.io/atlas-psychology-miniapp/
(в браузере открывается в демо-режиме; полная версия — внутри Telegram)

## Что внутри

| Раздел | Что делает |
| --- | --- |
| **Лид-магнит** | Тест «Карта внутреннего состояния» (10 вопросов → 4 «ландшафта»: Шторм, Пустыня, Туман, Гавань) → персональные рекомендации → форма (имя, цель, согласие) → гайд «7 техник самопомощи при тревоге»: читалка в приложении + PDF в чат от бота + 1 000 ✦ |
| **Практика (тапалка)** | «Сфера дыхания» в центре экрана: касание = искры ✦, энергия с регенерацией, уровни (Странник → Мудрец), бусты, ежедневная награда с серией, задания |
| **Лавка** | 10 товаров за искры: дыхательные практики (открываются в приложении), вебинар и воркбук (коды доступа), промокоды на программы, групповая сессия и консультация (уведомление куратору), метафорические карты. Часть товаров открывается с уровня |
| **Программы** | 5 курсов школы с описанием, модулями, ценой и заявкой (уведомление куратору) |
| **Профиль** | Пропуск, уровень, статистика, результат теста, покупки с кодами, настройки |

Диплинки: `t.me/<бот>/<app>?startapp=quiz` (сразу в тест — для рекламы), `guide`, `shop`, `practice`, `profile`, `ref_<id>` (приглашение).

## Архитектура

```
src/
  domain/      Чистая бизнес-логика (без браузера и Node): экономика, движок состояния,
               каталог, тест, гайд, практики, валидация. Покрыта тестами.
  telegram/    Обёртка WebApp API: fullscreen, safe area, тема, Main/Back/Settings Button,
               haptics, CloudStorage, requestWriteAccess, Stories, «на главный экран», downloadFile
  api/         Контракт Api + MockApi (локально, CloudStorage) + HttpApi (сервер, initData в заголовке)
  store/       Zustand: состояние, оптимистичные тапы с батчингом, навигация, тосты
  screens/     Главная · Практика · Лавка · Профиль · Тест · Гайд · Плеер практик
  sheets/      Нижние шиты: товар, программа, бусты, задания, награда дня, настройки
server/        Node API + Telegram-бот без фреймворков: проверка подписи initData (HMAC),
               тот же доменный движок, антифрод тапов, рефералы, выдача PDF, уведомления админу
scripts/       Генерация PDF-гайда из тех же данных, смоук-тест API
```

Ключевое решение: **один доменный движок исполняется и в браузере (мок), и на сервере.** Поэтому демо без сервера ведёт себя точно как продакшен, а переключение — одна переменная `VITE_API_URL`.

### Безопасность
- Сервер доверяет только подписанным `initData` (HMAC-SHA256 от токена бота, проверка `auth_date`).
- Тапы не доверяются клиенту: сервер ограничивает их доступной энергией и физически возможной частотой.
- Rate limit на пользователя, лимит размера тела, валидация всех входных данных, атомарные обновления по пользователю.
- Задание «подписка на канал» проверяется через `getChatMember`, «главный экран» — событием Telegram.

## Запуск локально

```bash
npm install
npm run dev          # фронтенд на http://localhost:5173 (демо-режим)
npm test             # юнит-тесты домена и проверки подписи
npm run smoke        # сквозной тест API с подписанными initData
npm run build        # продакшен-сборка в dist/
```

В браузере можно форсировать тему и диплинк: `?theme=light`, `?startapp=quiz`.

## Настройка Telegram-бота

1. **@BotFather → /newbot** — создайте бота, сохраните токен.
2. **/newapp** — создайте Mini App, привяжите к боту, URL: адрес GitHub Pages. Short name, например `app`.
3. **/mybots → бот → Bot Settings → Configure Mini App → Enable Mini App**, URL тот же; там же включите **Full screen** — приложение будет открываться на весь экран (код дополнительно вызывает `requestFullscreen()` на iOS/Android).
4. **Menu Button** настроится автоматически при запуске сервера (или вручную через BotFather).
5. Ссылка для рекламы лид-магнита: `https://t.me/<бот>/<shortname>?startapp=quiz`.

## Деплой

### Фронтенд (GitHub Pages — уже настроено)
Пуш в `main` → GitHub Actions прогоняет тесты, собирает и публикует. Переменные задаются в
**Settings → Secrets and variables → Actions → Variables**: `VITE_API_URL`, `VITE_BOT_USERNAME`,
`VITE_APP_SHORTNAME`, `VITE_CHANNEL_URL`, `VITE_CURATOR_USERNAME`.

Без `VITE_API_URL` приложение полностью работает автономно: прогресс хранится в Telegram CloudStorage пользователя (синхронизируется между устройствами).

### Бэкенд (для выдачи PDF в чат, уведомлений о лидах, рефералов, защиты от накрутки)
Любой хостинг с Node 20+ или Docker (Railway, Render, Fly.io, VPS):

```bash
cp .env.example .env   # заполните BOT_TOKEN, WEBAPP_URL, ADMIN_CHAT_ID, CORS_ORIGINS
npm run server
# или
docker build -t atlas-api . && docker run -d -p 8080:8080 --env-file .env -v atlas-data:/data atlas-api
```

Затем укажите публичный HTTPS-адрес API в переменной `VITE_API_URL` и перезапустите деплой фронтенда.
Данные хранятся в JSON-файле (`/data/db.json`) — хватает для пилота; для масштаба реализуйте интерфейс `Store` поверх Postgres.

### Обновить PDF-гайд
Тексты — в `src/domain/guide.ts`. После правок: `npm run guide:pdf` (нужен Chrome/Chromium, путь можно задать `CHROME_PATH`).

## Контент и данные

Все тексты, курсы, цены и товары — вымышленные, собраны в `src/domain/catalog.ts`, `quiz.ts`, `guide.ts` и легко меняются. Фотографии — Unsplash (Unsplash License, свободное коммерческое использование), лежат в `public/img`.
